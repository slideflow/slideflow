# Histology subtype with nnMIL

This example trains a lobular-versus-ductal slide classifier with the nnMIL model added to Slideflow. It can use H-Optimus-0 or Mettle feature bags. An RS model and a subtype model can score the same fold-specific encoder features without a second encoder pass.

## Setup

Use the `nnmil` branch of this Slideflow checkout and its PyTorch MIL dependencies. Supply a local, authorized checkpoint for the encoder. Keep the checkpoint and patient annotations outside the source tree.

| Annotation | Meaning |
| --- | --- |
| `slide` | Unique slide identifier |
| `patient` | Patient identifier; all slides from one patient stay in one fold |
| `histology` | `Lobular` or `Ductal` for training; keep mixed and other cases separate |
| `fold` | Patient-level fold assignment, fixed before training |

Use feature bags generated by the same encoder, tile size, and sampling method in training and inference. H-Optimus and Mettle bags are not interchangeable. The TAILORx model uses 1,024 tiles at 112 µm with H-Optimus-0, or 512 tiles at 224 µm with Mettle.

## Train a subtype head

```python
import slideflow as sf
import pandas as pd
from slideflow.mil import mil_config

project = sf.Project('/path/to/project')
dataset = project.dataset(tile_px=224, tile_um=112)
dataset = dataset.filter({'histology': ['Lobular', 'Ductal']})
folds = pd.read_csv('/path/to/patient_folds.csv', dtype={'patient': str})
assert not folds.patient.duplicated().any()
train_ids = folds.loc[folds.fold != 0, 'patient'].tolist()
val_ids = folds.loc[folds.fold == 0, 'patient'].tolist()
assert set(train_ids).isdisjoint(val_ids)
train = dataset.filter({'patient': train_ids})
val = dataset.filter({'patient': val_ids})

config = mil_config(
    'nnmil',
    lr=2e-4,
    epochs=40,
    bag_size=1024,
    model_kwargs={'hidden_dim': 256, 'dropout_p': 0.25},
)

project.train_mil(
    config=config,
    outcomes='histology',
    train_dataset=train,
    val_dataset=val,
    bags='/path/to/matched/feature_bags/fold0',
)
```

For Mettle bags, use `tile_um=224` and `bag_size=512`. Repeat the example for folds 1–4 and supply feature bags produced by the matching fold's RS encoder each time. The completed TAILORx subtype experiment used a fixed 40-epoch schedule on existing fold-specific features; its implementation and evaluation live in the separate `oncotype-tailorx` project. Report patient-level out-of-fold results and evaluate each external cohort without choosing an epoch or threshold on its labels.

## Score with the shared encoder

```python
import slideflow as sf
from slideflow.mil.models import NNMIL
import torch

extractor = sf.build_feature_extractor(
    'hoptimus0',
    weights='/path/to/base/pytorch_model.bin',
    lora='/path/to/rs/adapters/fold0.pt',
)
features = torch.as_tensor(extractor(tiles), dtype=torch.float32)
rs_head = NNMIL.from_rsimage('/path/to/rs/heads/fold0.pt')
subtype_head = NNMIL.from_rsimage('/path/to/subtype_heads/fold0.pt')

rs_head.eval()
subtype_head.eval()
rs_logit = rs_head(features.unsqueeze(0))[0, 0]
subtype_score = subtype_head(features.unsqueeze(0))[0, 0].sigmoid()
```

Repeat this for each matched fold and average the fold subtype scores. The subtype sigmoid is an uncalibrated score; it is not a clinical probability. For several slides from one patient, the external evaluation averaged slide scores after the fold ensemble.

## Validation and intended use

The development experiment fit on 951 lobular and 6,194 ductal TAILORx patients. Histology of other types was excluded from fitting and retained for coverage reporting. External evaluation used TCGA-BRCA and the UChicago, NorthShore, and Ingalls cohorts. Review subgroup sensitivity, calibration, and missing-slide coverage along with AUROC.

Histology classification accuracy does not validate an RS decision cutoff. The TAILORx-fitted rule-out scheme missed more than its 2% target in the outside hospitals. Keep thresholds as research evaluation outputs until an independent clinical policy is specified and validated.
